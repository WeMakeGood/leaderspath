AI-powered interactive learning platform with Claude chatbot integration for Divi 5.

== Description ==

LeadersPath powers an interactive AI learning community where learners interact with Claude AI chatbots enhanced with lesson-specific context files and executable skills.

= Features =

* 5 Custom Post Types: Lessons, Courses, Cohorts, Context Files, Skills
* 4 Divi 5 Modules: Chatbot, Context Library, Skills List, Lesson Meta
* Claude API integration with container and code execution support
* Transparency: Learners can view and download context and skills

= Requirements =

* WordPress 6.4+
* PHP 8.2+
* Divi 5
* Advanced Custom Fields Pro
* Anthropic Claude API key

== Installation ==

1. Upload the `leaderspath` folder to `/wp-content/plugins/`
2. Install and activate: Divi 5, Advanced Custom Fields Pro
3. Activate LeadersPath
4. Go to Settings > LeadersPath and enter your API key
